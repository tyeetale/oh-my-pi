# ompx notes

Personal notes for the `ompx` build of omp. This branch (`notes`) is never a PR source and is not merged into `ompx`.

- `AGENTS.md`: how the fork, contribution branches and the `ompx` integration branch fit together, plus the routines
  (add an edit, sync after a release, rebase when a dependency PR merges). The bare-repo container links to this file.
- `click-to-caret-contribution.md`: handoff for the `composer-click-to-caret` contribution (Discord draft, manual test
  checklist, review guide, PR body skeleton, changelog lines to add once a PR number exists).
- The launcher lives in the dotfiles repo: `dotfiles/bin/ompx`.
